# Jayceon Hou — Personal Website

A concise academic homepage combining an al-folio-style profile area with Minimal Light-inspired news, publication rows, awards and honors, and academic service.

The implementation is plain HTML, CSS, and JavaScript, so it can be previewed without Ruby, Jekyll, Node.js, or other build dependencies.


## Design references

- [al-folio](https://github.com/alshedivat/al-folio) — profile/about structure
- [Minimal Light](https://github.com/yaoyao-liu/minimal-light) — compact content sections and publication rows
